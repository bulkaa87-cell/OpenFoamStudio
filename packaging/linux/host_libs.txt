# Libraries that the Linux program takes from the system, not from its own
# folder. PyInstaller copies them from the build system (Ubuntu 22.04), and
# an old copy shadows the newer one of the system: then the graphics
# driver of the system does not load. Measured 2026-11-23 on Fedora 44:
# the old libstdc++ (GLIBCXX_3.4.30) stopped Mesa (needs 3.4.32), VTK found
# no OpenGL, tried OSMesa («libOSMesa not found») and crashed, and foamview
# found no Vulkan adapter. Without these files: VTK OpenGL and Vulkan on the
# Intel GPU.
#
# The spec (packaging/pyinstaller/openfoam_studio.spec) removes each
# top-level library whose name starts with a line of this file. All are on
# each Linux desktop. The .deb and .rpm require them (make_packages.sh),
# and the AppImage start script checks them (AppRun, check_deps.sh).
#
